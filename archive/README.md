# Archive

This directory contains deprecated ROS1 (Melodic) code from before the ROS2 Jazzy migration.

## Contents

- `ros1_launch/` - Old ROS1 XML launch files (replaced by Python `.launch.py` files)
  - `.catkin_workspace` - ROS1 catkin workspace marker
  - `mark_five_bot/` - Old launch files for the main robot package
  - `mark_five_description/` - Old launch files for robot description

## Note

This code is kept for reference only. The active ROS2 code is in the `src/` directory.
